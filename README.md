# 🕵️‍♂️ لعبة LE REPAIRE (الوكر) - شكون هو المحتال بيناتنا ؟

لعبة جماعية تفاعلية وحماسية مليئة بالذكاء والمراوغة (من صنف ألعاب **المحتال / Undercover / Spyfall**)، مبرمجة بالكامل بتقنيات **HTML و CSS و JavaScript الصافية** ومصممة باللغة العربية خصيصاً مع اتجاه **RTL** لتناسب الهواتف الذكية والأجهزة اللوحية والحواسيب.

## ✨ المميزات المدمجة في اللعبة

### 1. إعداد اللاعبين والمحتالين
- **عدد غير محدود من اللاعبين** (من 3 إلى 16 لاعباً).
- **تسمية كل لاعب باسمه** : كتابة الأسماء بسهولة.
- **زر 🎲 أسماء جزائرية** : يملأ أسماء اللاعبين فوراً بأسماء جزائرية شعبية (أمين، سارة، مهدي، ياسمين، كريم، لينا، سفيان، إلخ).
- **أيقونات وأفاتار مرحة** : بالضغط على الأيقونة يمكن تغيير شكل كل لاعب.
- **تحديد عدد المحتالين** مع احتساب ذكي للعدد الموصى به تلقائياً حسب عدد المشاركين.

### 2. نظام التلميحات للمحتال (4 أنماط)
1. **💡 تلميح خاص وذكي** : يحصل المحتال على تلميح ذكي يصف الكلمة ليتمكن من التمويه والمراوغة دون أن يُكشف.
2. **🏷️ معرفة الصنف فقط** : يعرف المحتال الصنف فقط (مثل : *أطباق جزائرية*).
3. **🎭 وضع الكلمة الفخ (Undercover)** : يحصل المحتال على كلمة قريبة جداً (مثال : *الكسكس* مقابل *الرشتة*).
4. **🚫 الصعب جداً (بدون أي تلميح)** : المحتال في الظلام تماماً وعليه الاعتماد على حدسه وذكائه !

### 3. بنك غني بالكلمات والمواضيع
- 🥘 **أطباق جزائرية** : الكسكس، الشخشوخة، الرشتة، الكرانطيطا (الحامي)، شربة فريك، المحاجب، البوراك، الدوبارة البسكرية، طاجين الزيتون، المثوم، الزفيطي (المهراس)، المقروط، قلب اللوز، التريدة، الدولمة، اللوبيا، شطيطحة بطاطا، البغرير، الطمينة، طاجين الحلو، البركوكس، السفة...
- 🇩🇿 **أماكن ومعالم في الجزائر** : مقام الشهيد، قصبة الجزائر، حصن سانتا كروز (وهران)، جسور قسنطينة المعلقة، طاسيلي ناجر (جانيت)، آثار تيبازة الرومانية، قصور وادي ميزاب (غرداية)، تيميمون الواحة الحمراء، كنيسة القديس أوغسطين (عنابة)، قصر المشور (تلمسان)، رأس كربون ويما قورايا (بجاية)، واحة تاغيت (بشار)، آثار جميلة، حديقة الحامة، جبال الشريعة، الأسكرام (الهقار)...
- 🌍 **أماكن ومعالم حول العالم** : برج إيفل، أهرامات الجيزة، تمثال الحرية، الكولوسيوم، تاج محل، سور الصين العظيم، برج خليفة، ماتشو بيتشو، ساعة بيغ بن، جبل فوجي، كنيسة ساغرادا فاميليا، البتراء، قنوات البندقية، شلالات نياجرا، برج بيزا المائل...
- 🎭 **شخصيات وفنانين جزائريين** : الشاب خالد، الشاب حسني، عثمان عريوات، صالح أوقروت (صويلح)، دحمان الحراشي، إيدير، بيونة، رويشد، وردة الجزائرية، الحاج محمد العنقى، الشيخة الريميتي، المفتش الطاهر، فلاق، الشاب مامي، رياض محرز، رابح ماجر، معطوب الوناس، الشاب بلال...
- 🌟 **شخصيات ونجوم عالميين** : مايكل جاكسون، ليونيل ميسي، كريستيانو رونالدو، ليوناردو دي كابريو، تشارلي تشابلن، بوب مارلي، ويل سميث، فريدي ميركوري، جاكي شان، مستر بين، ألبرت أينشتاين، زين الدين زيدان، كيليان مبابي، مورغان فريمان، بيونسيه...
- ✏️ **إضافة كلماتكم الخاصة** : زر لإضافة أي كلمة سرية وتلميح خاص بكم وحفظها في المتصفح.

### 4. مراحل اللعبة الممتعة
1. **كشف الأدوار السرية (Pass & Play)** : تمرير الهاتف بين اللاعبين مع زر كشف محمي لمنع التلصص.
2. **طاولة الحوار والنقاش** : اختيار عشوائي لأول لاعب يتكلم مع مؤقت تنازلي بأصوات تفاعلية.
3. **التصويت والإقصاء الدرامي** : نافذة تشويق لفرز الأصوات، ثم كشف هوية اللاعب بمؤثرات صوتية واقعية (Web Audio API).
4. **الفرصة الذهبية الأخيرة للمحتال** : إذا تم كشف المحتال، يمكنه كتابة الكلمة السرية؛ إذا حزرها يخطف الفوز فوراً !
